## Lessons
- Call results that the original stores into a struct member are assigned straight to the member (no local).
- Model loops the way VC6 strength-reduces them: index/pointer pair in the for-init, `for (i = count; i > 0; i--)` over `*entry`, locals declared in frame order (first declared = highest address).
- A float constant multiplied before `(int)` shows up as `fmul dword ptr [const]`; read the constant from the exe.
- `if (x == 1) return 1;` first with a literal makes VC6 load eax=1 before the compare.
